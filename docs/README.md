# TaskMetrics

TaskMetrics is a cross-platform mobile task management application built with React Native (Expo) and Firebase. It helps users organize, track, and manage their daily tasks with a clean, modern interface and real-time notification reminders.

## Purpose

TaskMetrics provides individuals and small teams with a lightweight yet powerful tool to manage tasks, set deadlines, track completion rates, and receive timely reminders — all from a mobile device.

## Main Users

- **Individuals** — Personal task tracking and productivity management
- **Students** — Assignment and deadline management
- **Professionals** — Work task organization and prioritization

## Main Features

| Feature | Description |
|---------|-------------|
| Task CRUD | Create, read, update, and delete tasks |
| Categories | Organize tasks by Work, Personal, Study, Health, or Other |
| Status Tracking | Track tasks as Pending, In Progress, or Completed |
| Deadline Management | Set and view deadlines with overdue indicators |
| Dashboard Analytics | View task statistics (total, completed, pending, overdue) |
| Weekly Productivity | Track weekly completion rates |
| Search & Filter | Search by title, filter by status |
| Reminder Notifications | Schedule local notifications with custom alarm sounds |
| Dark Mode | Toggle between light and dark themes |
| Firebase Sync | Real-time cloud synchronization (when configured) |
| In-App Notifications | Alerts for task completion and deletion |
